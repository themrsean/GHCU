# Grading Window — Keyboard Shortcuts

---

## Editing

| Shortcut | Action | Notes |
|---|---|---|
| **Ctrl/⌘ + Z** | Undo | Undo the most recent edit in the current report. |
| **Ctrl/⌘ + Y** | Redo | Redo an undone edit in the current report. |
| **Ctrl/⌘ + S** | Save report | Forces a manual save of the current report (autosave also runs after edits). |

---

## Report Navigation

| Shortcut | Action | Notes |
|---|---|---|
| **Ctrl/⌘ + ,** | Previous report | Selects the previous report in the report list (wraps around). |
| **Ctrl/⌘ + .** | Next report | Selects the next report in the report list (wraps around). |

---

## Find / Replace

| Shortcut | Action | Notes |
|---|---|---|
| **Ctrl/⌘ + F** | Open Find bar | Opens the find bar in **Find** mode. |
| **Ctrl/⌘ + R** | Open Find/Replace bar | Opens the find bar in **Replace** mode. |
| **Esc** | Close Find bar | Hides the find bar and clears find highlighting. |

---

## Font Size

| Shortcut | Action | Notes |
|---|---|---|
| **Ctrl/⌘ + +** | Increase font size | Increases editor font size by 1pt. *(Implemented as Ctrl/⌘ + `=` key)* |
| **Ctrl/⌘ + -** | Decrease font size | Decreases editor font size by 1pt. |
| **Ctrl/⌘ + 0** | Reset font size | Resets font size to the default. |

---

## Comments

| Shortcut | Action | Notes |
|---|---|---|
| **Ctrl/⌘ + /** | Open Comment Browser | Opens the reusable comment browser for inserting feedback. |

---

## Deploy / Publish Feedback

| Shortcut | Action | Notes |
|---|---|---|
| **Ctrl/⌘ + E** | Deploy current report | Copies the currently selected report into the corresponding student repository (`feedback/`). |
| **Ctrl/⌘ + Shift + E** | Deploy all reports | Copies *all* reports into their mapped repositories (`feedback/`). |
| **Ctrl/⌘ + D** | Publish current report | Deploys the current report and pushes it to GitHub. |
| **Ctrl/⌘ + Shift + D** | Publish all touched repos | Publishes feedback for all repositories that have had reports deployed during this session. |
